# NIRUPRESENCE QuickShell

Personal Omarchy/QuickShell companion for n.rudolfsson.net. Version 0.4.4.

Install: `sh install.sh` from the repository root. This keeps local settings, backs up existing plugin files and requests a shell plugin rescan.

The server owns AUTO, manual Offline and the nightly presence window. Heartbeat runs when the plugin loads, every five minutes thereafter, with short retries when the server does not confirm a signal. Music sync remains independent.

Source is published for personal use; no tokens or local configuration belong in Git.
